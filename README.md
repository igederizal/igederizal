### CDN Simulator

[![Go](https://img.shields.io/badge/Go-00ADD8?style=flat-square&logo=go&logoColor=white)](https://github.com/igederizal/cdn-simulator)
[![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)](https://github.com/igederizal/cdn-simulator)
[![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white)](https://github.com/igederizal/cdn-simulator)
[![CI](https://github.com/igederizal/cdn-simulator/actions/workflows/ci.yml/badge.svg)](https://github.com/igederizal/cdn-simulator/actions/workflows/ci.yml)

[![Repo](https://img.shields.io/github/repo/igederizal/cdn-simulator?style=social)](https://github.com/igederizal/cdn-simulator)

Multi-region CDN written in Go: 3 containerized edge servers, latency-based L7 router, origin server, and Redis cache — with stale-while-revalidate, tag/pattern invalidation, Prometheus metrics, Grafana dashboards, and a CI pipeline that runs unit tests plus a live MISS → HIT smoke test on every push.

**Self-audited against OWASP:** 11 findings (4 high severity — unauthenticated admin API, SSRF, exposed Redis & Grafana), all fixed and locked in with regression tests in CI.
